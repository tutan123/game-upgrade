# 10 · 管理器与数值属性系统

## 10.1 单例方式

- `SingletonAsMono<T>`（SingletonAsMono.cs）：MonoBehaviour 单例，`Instance` 先 `FindObjectOfType<T>`，没有则 `new GameObject(typeof(T).Name).AddComponent<T>()` + `DontDestroyOnLoad`。`Awake()` 用 `JsonMapper` 从 `GameData.GetValue(GetDataKey())` 反序列化一个按类名命名的 `Dictionary<string,string>` 持久化数据。
- `SingletonAsClass<T>`：普通类惰性单例。
- 静态管理器（LanguageMrg/SdkMrg/LoadMrg/Config/Tool）。

## 10.2 各 Mrg 职责

| 管理器 | 单例 | 职责/依赖 |
|---|---|---|
| **GlobalMrg** | Mono | 全局游戏态：`videoNode`(当前视频节点) + `videoState`(None/GameScene/Video360Scene/Map)，各 UI 据此判断流程 |
| **GameDataMrg** | Mono | **核心数据/存档/数值管理器**（见 §10.3）；引 Xlsx_Event_Query/Item_Query/WineList_Query、ABMrg、EventManager；`OnApplicationQuit`→存档 |
| **LanguageMrg** | static | `GetText(key)` 按 `GameData.Language` 取 `Xlsx_Language` 的 Chinese/English，还原 `\n`/`\t` |
| **AudioMrg** | Mono | `ObjectPool<AudioSource>` 播放音效，到期回池；音量 `GameData.GetOpenAsNum("Sound")`(默认 0.3) |
| **SdkMrg** | static | Steam：`IsDownLoadDlc`、`IsDown4KDlc`、`UnLockAchievement` |
| **UpdateMrg** | Mono | `UnityEvent<float> OnUpdate` 每帧驱动，Timer 挂在这上面 |
| **InfoTipsMrg / InfoTipsRightMrg / InfoTopTipsMrg** | Mono | 各自队列 + 协程节流 → `UiManager.ShowInfoTips/...` |
| **EventContentMrg** | Mono | **视频流程事件中枢**：`LoadEventContent()` 注册几十个 `EventManager.AddListener(MessageType.Video,...)`；`Update()` 处理按键；退出存档 |
| **CameraShakeMrg / MouseAutoHideMrg / AutoGCCleanerMrg** | Mono/手写 | 相机震动 / 鼠标闲置隐藏 / 定时轻量 GC(`GC.Collect(0,Optimized)`)，仅 idle |
| **LoadMrg** | static | 场景异步加载 + 进度窗，Map3D 再 Additive 加载 Day/Night，卸载 |
| **FolderDataMrg** | Mono | 文件夹 UI 元素对象池 |

**依赖闭环**：`GameDataMrg(数据) + EventManager(消息) → EventContentMrg(xnode 事件→UI/数值) → UiManager → Windows/Item → PropertyData.AddTypeValueAsShowTips → GameDataMrg.Add/GetProperty`；`GlobalMrg` 供流程态，`UpdateMrg`+`Timer` 供帧/延时。

## 10.3 数值/属性系统（PropertyData + GameDataMrg）

### PropertyData 结构（PropertyData.cs）
```
VideoIfType videoIfType;      // Gre / Less —— 条件判断方向
PropertyType PropertyType;    // Value / Item / Property / Other（分桶）
string TypeName;              // Value 桶的 key
ItemType itemType;            // Item 桶的 key
PropertyTypeValue propertyTypeValue; // Property 桶的 key
OtherType otherType;          // Other 桶的 key（Round/QteSucCount/QteFailCount）
int PropertyValue;            // 数值
float addPropertyTime;        // 时机：视频播到该秒才生效
bool isShowTips;              // 是否显示浮动提示
bool isEx;                    // 已执行标记
bool isRound;                 // 是否"回合"作用域
bool isAlwaysEx;              // 是否"常驻/可重复"（已解锁也执行）
```

### 分桶与 key 约定（GameDataMrg.cs）
所有数值最终落到 `SavedData.Data`（`Dictionary<string,string>`），key 统一为 **`property_<type>_<name>`**；回合变体为 **`property_<type>_<CurRound>_<name>`**：
- `GetProperty(name,type="Nor",def=0)`(:426)：先取装备加成 `GetEquipAdd()`，再 `GetPropertyNorEquip(name,type,def)` 读原始值（特判：IsMorning 返 0/1、KPI+4000、CapacityForLiquor 再加回合属性），最后加上装备加成。
- `GetPropertyNorEquip`(:520)：真正读 `_saveData.Data["property_"+type+"_"+name]`。内置别名重定向（`TSGSNFavorability→XFPFavorability`、`XXSN→XXG`、`WY→LBN`、`LXY→XJM`、`GonShiZhiChang→Money`）与默认值（`Stamina=5`、`Wisdom=5`、`Money=352`、`Execution=10`、`CapacityForLiquor=100`、`XinDonLiShangXian=20`、`YaLiShangXian=100`）。
- `AddProperty(name,count,type="Nor")`(:449)：特判 `TmpPlayerHp` 封顶到 `PlayerHp`、`Item` 红点、好感度别名、`JianJin/GonShiZhiChang` 重定向 Money；收口 `Execution=Min(num,上限)`、`Pressure=Max(0,num)`、`JiNengDian/TmpJiNengDian` 上限 12；写 `_saveData.Data[...]` + 派发 `GameMessageType.UpdateProperty` + `Tool.CheckAchievement()`。
- `SetProperty`(:581)：直接覆盖并派发。
- **回合变体**：`GetRoundProperty/AddRoundProperty/SetRoundProperty`(key 带 `CurRound`)。
- `GetEquipAdd()`(:888)：遍历装备槽 `ZbType.TouBu..PeiShi3`，取 `Xlsx_Item` 的 `AddType[i]/AddValue[i]` 累加。

### PropertyData 应用（Tool.cs 扩展方法）
- `AddTypeValue(this PropertyData)`(:1196)：按 `PropertyType` switch，读写都根据 `isRound` 走 `AddRoundProperty` 或 `AddProperty`。
- `AddTypeValueAsShowTips`(:1247)：对 `TmpPlayerHp` 按 `DiFanZhengJia`（敌方加伤%）缩放；`EnemyHp` 按 `ZiJiZhengJia`（我方加伤%）缩放。**这是战斗数值平衡的中枢。**
- `AddTypeValueAsShowTipsNotAdd`(:1280)：只拼提示 UI。
- 条件校验 `IsSuc(List<PropertyData>)`(:987)：空=true；每个元素 `videoIfType==Gre` 要求当前值 **>** 阈值，`Less` 要求 **<** 阈值（严格），否则 false。`IsSucOr`(:1053) 为 OR 版本。

### 存档持久化
- `SavedData`(SavedData.cs:25)：`Time/Key/Round=1/SavedName/...` + **`Dictionary<string,string> Data`**。属性、解锁、聊天、任务、ItemTime 全是字符串。
- `GameDataMrg.Save/NewSaved/CurNewSaved/AutoSave/CoverSave/LoadSaveData`(:638-776) 用 `Guid.NewGuid()` 作档名写 `GameData.SetString(GetDataKey(key), JSON)`；`_saveKeys` 上限 20、`_autoSaveKeys` 上限 6（LRU 淘汰）。
- 底层 `GameData.cs:75-150`：静态字典 `_dataDic`，静态构造读 `persistentDataPath/data.dat`，`Tool.Decrypt`(Rijndael ECB+PKCS7，key=Base64) → JSON → 字典；`Save()` 反向加密写盘。`CurDataKey = CurKey + "_Data"`。

> 注意：反编译里 `Tool.Key="kljsdkkdlo4454GG00155sajuklmbkdl"`（30字符）不是合法 Base64 长度，更像占位/混淆；实际应为合法 Base64 key。存在 `Encrypt/Decrypt(byte[])`（Rijndael）与 `Encrypt/Decrypt(string)`（AES，返回 hex，用于资源路径/文件名混淆 `GetFileDecryptName`）两套。

## 10.4 值得学习的设计

1. **属性分桶 + 统一字符串 key**：`property_<type>_<name>` + 回合变体 `property_<type>_<CurRound>_<name>`，一个字符串字典承载整套数值系统。
2. **PropertyData 作为"可配置的效果描述"**：数值、作用域、时机、展示、重放全部收口在一个能被打包/写进 xnode 节点的对象里。
3. **效果与反馈三层分离**：`AddTypeValue`(只改数值) → `AddTypeValueAsShowTips`(带增益修正) → `AddTypeValueAsShowTipsNotAdd`(只拼提示 UI)。
4. **事件驱动解耦**：`GameDataMrg.AddProperty` 只派发 `UpdateProperty`，UI 自行刷新。
5. **存档统一为字符串字典 + 加密**：一种格式承载全球 + 各存档 + 各属性。
